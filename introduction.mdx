## How It Works

<Steps>
  <Step title="Register & Verify">
    Create an account via `POST /api/auth/register`, then complete KYC verification so you can deposit and wager real money.
  </Step>
  <Step title="Fund Your Wallet">
    Use the PayPal integration to create a deposit order and capture payment. Funds appear in your double-entry ledger wallet instantly after webhook confirmation.
  </Step>
  <Step title="Create or Join a Game Room">
    Create a private room with a stake amount, or join an existing open room. Both players' stakes are locked until the match concludes.
  </Step>
  <Step title="Play & Receive Winnings">
    Submit the match result. The platform verifies the result (optionally with a supervisor present), transfers winnings, and records every transaction in the ledger.
  </Step>
</Steps>

## Key Capabilities

| Capability | Details |
|---|---|
| **Authentication** | JWT RS256 — asymmetric signing, short-lived access tokens + refresh tokens |
| **KYC** | Manual identity verification required before real-money play |
| **Wallet** | Double-entry ledger; every debit has a matching credit |
| **Deposits** | PayPal Orders API v2 with HMAC-SHA256 webhook verification |
| **Real-Time** | WebSocket/STOMP over `/ws/arena`; Redis Pub/Sub for multi-instance fan-out |
| **Supervision** | Supervisors earn commissions on every supervised game they oversee |
| **Complaints** | Structured complaint workflow with supervisor-led resolution |

<Note>
  All financial operations require a verified KYC status. Ensure your account is verified before attempting deposits or joining real-money game rooms.
</Note>
